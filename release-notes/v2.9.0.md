# Geekify v2.9.0 - Release Notes

**Release Date:** 20 November 2026

### What's New
- **Minimal Settings redesign**: Reorganized the main Settings dashboard and all Settings subpages into clean grouped category cards with a functional Settings search bar while preserving Geekify's active theme system.
- **Advanced Font Manager & Google Sans**: Added a dedicated Fonts screen under Typography & Density supporting custom TTF/OTF import via Android SAF, bundled Google Sans, on-demand open-source font downloads (Lato, Roboto, Comic Neue, Atkinson Hyperlegible Next), live preview, and system font reset.
- **Appearance hub**: Renamed Personalization Studio to Appearance across Settings headers, dialogs, and search results while keeping legacy search keywords supported.
- **Redesigned About Geekify screen**: Added a Metrolist-inspired About Geekify layout featuring app identity details, creator profile card, GitHub and Releases quick links, and legal/acknowledgement dialogs.
- **Recommendation feedback loop**: Wired More Like This and Less Like This feedback actions in Home and Now Playing directly into recommendation ranking.

### Improvements
- **Duplicate settings cleanup & consolidation**: Removed redundant navigation entries from the Appearance hub, consolidated Skip Silence, Loudness Normalization, and Crossfade Duration into Player & Audio, and removed duplicate manual update-check entries from About Geekify.
- **Light Theme & ASCII artwork adaptation**: Repaired Light Theme surface contrast, text legibility, Liquid Glass tinting, and reversible Light-mode ASCII artwork color adaptation across all screens and player views.
- **App-wide long-press track actions**: Enabled consistent long-press track menus across Home shelves, Liked songs, Playlists, Recents, Artist, Collection, and Downloads screens without breaking short-tap playback.
- **Update Dialog pagination & polish**: Added paginated GitHub Release history loading, improved changelog expansion controls, and made the What's New header adapt cleanly to narrow widths and large font scales.

### Bug Fixes
- **Settings back-navigation fix**: Fixed direct Settings shortcuts (Typography & Density, Navigation, Home Screen, Player & Audio, Lyrics, and Search results) so pressing Back returns directly to Settings while preserving nested Appearance navigation.
- **Lyrics retrieval & preview alignment**: Fixed BetterLyrics HTTP 401 circuit-breaker fallback with a clean No Lyrics Found empty state, and fixed the Lyrics Appearance preview header so Replay and Play/Pause controls no longer wrap or clip.
- **Show Remaining Time independence**: Fixed Seekbar remaining-time visibility and Player remaining-time format toggles so changing one no longer overwrites the other.
- **Now Playing navigation & curated feed accuracy**: Fixed artist and album tap navigation from Now Playing, improved curated recommendation language descriptions, and filled Home grid rows consistently.
