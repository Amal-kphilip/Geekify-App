# Geekify v2.8.0 - Release Notes

**Release Date:** 19 November 2026

### What's New
- **Personalization Studio**: Added a centralized customization hub covering 13 categories including dark surface variants, AMOLED pitch black, accent color palettes, Liquid Glass presets, ASCII background performance profiles, home screen layout modes, navigation bar tab selection and ordering, 6 expanded player layouts, mini-player styles, gestures, global typography, synchronized lyrics appearance, playback preferences, widgets, and launcher icons.
- **Multi-provider synchronized lyrics**: Added automatic lyrics retrieval across SimpMusic, BetterLyrics TTML, LrcLib search and exact matching, KuGou synchronized LRC, YouTube Music timed lyrics, and YouTube subtitle transcripts with word-level and line-level highlight support, offline phonetic romanization, per-song timing offset controls, and an inline source switcher.
- **Offline downloads and audio caching**: Added a persistent offline download manager with progress tracking, pause, resume, retry, Now Playing download controls, and offline playback fallback.
- **Song recognition**: Added microphone-based Shazam audio fingerprinting and recognition history with direct playback and quick settings tile integration.
- **Home screen widgets and integrations**: Added Now Playing and Song Recognizer home screen widgets, ListenBrainz scrobbling, and Discord Rich Presence support.

### Improvements
- **Streaming and playback engine**: Upgraded the playback pipeline with Koin dependency injection, multi-client extraction fallback, SABR and PO token recovery, categorized playback errors, network state monitoring, next-track preloading, and dual-player equal-power crossfade.
- **Global typography and text scaling**: Applied the selected application font family and text scaling across Material typography styles, explicit text sizes, marquee titles, search fields, and the expanded player.
- **Unified settings hierarchy**: Consolidated all appearance, background, player, navigation, and icon customization controls into Personalization Studio with deduplicated deep search routing.

### Bug Fixes
- **Lyrics lookup normalization and fallback**: Fixed lyrics retrieval failures caused by video title suffixes, featured artist tags, missing track duration metadata, and single-provider lookup errors.
- **Player layout switching**: Fixed tonearm synchronization gating when switching away from the vinyl player layout and removed duplicate cover rendering in fullscreen artwork mode.
- **Dynamic navigation bar layout**: Fixed bottom navigation bar spacing and tab ordering when destinations are hidden or reordered.
