# Geekify v2.7.8 - Release Notes

**Release Date:** 16 November 2026

### Improvements
- **Smoother animated background**: Added a hardware-accelerated GPU shader background renderer with adaptive fallback for smoother animation on supported devices.
- **Home header gradient**: Removed the Home header gradient so the animated background shows through.
- **Tablet ASCII detail**: Scaled background character grid on tablets so visual detail matches phones.
- **Dependency updates**: Updated Coil to 3.6.3, Kotlinx Serialization to 1.13.0, KSP to 2.3.13, and AndroidX libraries (Core KTX 1.19.1, Navigation Compose 2.10.2, Hilt Navigation Compose 1.4.0, WorkManager 2.12.0, DataStore 1.3.0, Collection KTX 1.7.0).

### Bug Fixes
- **Playback-state indicators**: Fixed Home daily picks rows always displaying a Play icon while their track was actively playing.
